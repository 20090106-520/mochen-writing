# 先认结构，再填内容

## 结构的用处是排查，不是套模板

套模板会得到一部「结构完整」但没有一本书的书。
结构的真正用处是：**写完一段之后，能有一把尺子量它缺了哪一块。**

## 先做一件事：给这一段认一个结构

常用的几个，认一个就行，不要叠：

- **三幕**：起（交代与触发）— 承（对抗与升级）— 合（收束与代价）。
  长篇的分卷基本就是三幕的放大。
- **黄金三章**（短篇与开篇用）：第一章立住「有什么不一样」，第二章让人物动起来，
  第三章给出一个他回不了头的选择。**第三章没有那个选择，开篇就废了**，
  因为读者此时还没有任何理由追下去。
- **起承转合**（单章用）：起 = 进场面，承 = 事情推进，转 = 一次不可逆，合 = 停下来。

## 认完之后，做一张对照表

左边写结构件，右边写它在**这本书里**对应哪一段。填不上的那一格就是缺口。

例（起承转合，单章）：

- 起：她回到旧宅，门没锁。
- 承：翻出母亲留下的账本，发现数目不对。
- 转：账本最后一页写着她自己的名字。
- 合：她把账本合上，出门去问当年经手的人。

这张表的作用在事后才显出来：写完回看，哪一段是空的、哪两段重复了，一眼就看见。

## 短篇与长篇的差别

- **短篇**按**场景功能**分，不按字数。每个场景必须至少推进一件事：给信息、给压力、给选择。
  一个只「交代气氛」的场景在短篇里就是浪费。
- **长篇**按**状态变化**分。每一卷结束时，某个人的处境必须与卷首不同；
  哪一卷结束时没变，那一卷就是过渡卷——过渡卷可以有，但不能连着两卷。

## 写完之后的自查

1. 每个结构件都填上了吗？空的那一格补，还是承认这一段不完整？
2. 换一本完全不同的书，这一格还成立吗？**成立 ⇒ 那是废话，删掉。**
3. 转折那一格，真的不可逆吗？能往回走一步就不叫转折，那叫插曲。

## 不要做的事

- 不要因为「结构完整」就以为这一段写好了。结构完整和好看是两件事。
- 不要在同一段里套两个结构再对不上号。那不是复杂，是没想清楚。
- 不要在动笔前把对照表写完就不再看。它是**写完之后**才用来量东西的。
