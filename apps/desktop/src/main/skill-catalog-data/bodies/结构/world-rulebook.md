# 把设定写成能照做的规则

## 设定不是介绍，是规则

「这个世界的魔法基于血脉」——这是**介绍**，读者知道了，然后呢？
「施法需要本人的血，且血必须是自己主动给出的，被取走的血无效」——这是**规则**，
读者立刻能判断接下来发生的事合不合法，作者写的时候也不会自己撞墙。

**检验办法**：拿一条设定，编一个场景，看能不能判断出结果。
判断不出来，它就还不是规则。

## 一条规则要写全三样

1. **能不能**：什么条件下成立。
2. **代价**：用了会失去什么。没有代价的规则会掏空所有紧张感。
3. **边界**：什么情况下失效。边界是让规则变得可信的地方——
   有了边界，「他违反了这一条」才是可能发生的事。

三样缺一，这条规则就还不能用。

## 照着做的写法

写完一条，紧接着写**一个成立的情形**和**一个越界的情形**：

规则：夜行者不能在有灯火的地方施展能力。

成立：客栈里，他吹灭了灯才敢抬手。
越界：有人在他身后点灯——他没察觉，于是能力在他手里散了，人没事，
但他三个月内不能再次施展。

越界的情形比成立的情形更能暴露规则的漏洞。写不出越界的情形，说明这条规则其实没有边界。

## 收尾之前做两件事

1. **找矛盾**：两条规则撞在一起时，按哪条算？把答案写下来。
   「按哪条算」没有答案的规则表，写到中段一定会出戏。
2. **找万能**：如果某个人物在任何情况下都能用这个能力，那这条规则对它等于没有。
   想办法给他一个具体的、不方便使用它的处境。

## 放在哪

写好的规则放进这本书的「素材」类文稿里，标题写「世界规则」。
之后任何一轮讨论剧情，都可以把它挂进上下文当约束用——
它是**可执行的说明书**，不是背景介绍。
