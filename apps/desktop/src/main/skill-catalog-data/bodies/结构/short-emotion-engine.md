# 短篇先定读完那一口情绪

改编自 zenstory-ai/oh-story-claudecode 的 story-short-write（短篇以情绪为目标的写法，MIT）。只搬方法，不搬原文。

长篇靠追读养着，可以绕路、可以埋线、可以慢慢热。
短篇是一口气读完的东西，**读者的耐心只有一次**，所以短篇的规矩和长篇不一样：
不是「把故事讲完整」，是**把一种情绪送到**。

## 动笔前只定三样

1. **读完的感觉**。一句话，越具体越好——不是「感动」，是
   「替她松了口气，又有点酸」。感觉定不下来就先别写，
   短篇没有「写着写着就有感觉」这回事，写着写着只会跑偏。
2. **故事核**。一句话说完谁、碰上什么、最后变了什么。
   一句话说不完的故事核，是长篇的量，塞进短篇只会两头都做不好。
3. **爆点在哪**。短篇通常只有一次爆点（反转、揭底、情绪决口），
   定下它的位置，前面的每一场都在往那里送东西。

## 所有内容为情绪服务

写完每一段问：**这段把读者往那个感觉推了吗？**
推不了的性质再好也删——人物背景再有意思，与这一口情绪无关就不写；
次要人物再可爱，不喂情绪就砍成一笔带过。
长篇里这叫可惜，短篇里这叫跑题。

## 节奏的粗规矩

- **开头三段内进事**。短篇没有序章的位置，第一段就在故事里。
- **中间不换频道**。一条情绪线走到底，副线留给长篇。
- **结尾停在情绪的余音上**，停在动作或一句话上——
  解释这口情绪是怎么产生的，等于把读者的余味没收了。

## 不要做的事

- 不要把长篇的开头法搬过来。世界观铺陈、家谱式介绍，短篇里全是漏气的地方。
- 不要为了字数加水。短篇缺的不是字，是把情绪送到的最后一推。
- 不要在一个短篇里塞两个爆点。两次爆点互相拆台，读者哪一次都不炸。
