# 一章的细纲只写一件事：变了什么

## 门禁：没有细纲就不要写正文

这一条是硬规矩，不是建议。
没有细纲就动笔写出来的东西，事后无法判断它是「照纲写的」还是「跑偏了」——
于是唯一的处理办法是重写。重写一章的时间，远比写四行细纲长。

**判据很简单**：这一章的「变了什么」写不出来，就先别写正文。

## 四行细纲

每章一份，四行，不多不少：

1. **谁在推什么**——主动的那个人，和他这一章想要的东西。
2. **什么挡着**——具体到一句话能说清的阻力。
3. **情节点**——三到五个，每个写「（谁）做了什么，导致（什么）」。
4. **停笔点**——这一章的最后一句把话停在哪里。

## 情节点要写因果，不写时间

「他去了码头」是时间线。
「他去了码头，因为信上说船提前一天到，而那天他妹妹正好在码头」是情节点。

判据：**能不能在两个情节点之间用「所以」连起来。**
连不上的那个节点，中间少了一环。

## 停笔点不是结尾，是欠账

停笔点定的是**这一章结束时，读者手里攥着什么没兑现的东西**。
不是「本章完」。

写完细纲，检查两件事：

- 本章结束时，有没有一笔账是本章开头没有的？（没有 ⇒ 这一章没在推剧情。）
- 下一章开头，能不能直接接上这笔账？（不能 ⇒ 停笔点选错了。）

## 字数目标写明确

细纲里把这一章的目标字数写死。
不写就会滑向「写多少算多少」，而临场判断字数的结果，
通常是「写到觉得够了就停」——那通常比需要的长三成。

欠了不要靠加戏补，**超了压缩一次**。加了戏的这一章多半会留下水分。

## 不要做的事

- 不要把细纲写成正文的一句摘要。它是规格，不是预告。
- 不要一章一份超过五行。四行还看得住，八行就没人会真的对。
- 不要在写完正文之后再补细纲来「对上」——那不是门禁，是事后凑数。
