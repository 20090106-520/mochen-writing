# 给每个人物钉一条动机链

改编自 zenstory-ai/oh-story-claudecode 的 story-long-write（人物设计，MIT）。只搬方法，不搬原文。

## 人物塌房的三种样子

- 所有人在用同一个腔调说话（这一条另有技能管，见「让人物说话不像一个人」）。
- 人物做了一件事，回头说不清自己为什么这么做。
- 人物突然变好，或者突然变坏，中间没有过程。

后两种的根子是同一个：**这个人只有设定，没有动力**。
设定回答「他是什么样的人」，动力回答「他此刻为什么动」。
只有设定的人，交给模型或自己临场发挥时，动作就是随机的。

## 动机链三节

给每个主要人物钉一条，三节都要有具体的东西：

1. **他想要什么**——不是「想变强」，是「让阿姊不再咳血」。
2. **他愿意付什么代价**——代价必须是他真付得起的。付不起的代价不构成选择。
3. **他不肯跨过哪条线**——这一节最关键，也最常被省略。

例（老账房）：

- 想要：把铺子撑到年底，让孙女赎身。
- 愿意付：熬夜、赔钱、替人背下不属于自己的账。
- 不肯跨：不主动骗人。有人来骗他，他可以看穿、可以不说，但不会先开口。

## 每一场戏写之前问一句

**这一场里，这个人离他那条线更近了，还是更远了？**

- 更近 ⇒ 这场戏写对了，哪怕他这一场一个字都没说。
- 更远 ⇒ 也不是不行，但要清楚这一场在干什么。
- **没动** ⇒ 他这一场不该在场。把他挪走，或者给这一场加一个「他必须动」的理由。

这一问是这份技能的全部。它比「这个人物的性格是什么」有用得多，
因为性格是描述，这一问是可执行的。

## 群像场面

两个以上主要人物同场时，两条链必须**互相顶住**——
他要的东西正好是他要的东西的障碍。
顶不住的那一场就只是两个人在一个屋里说话。

写完回看一遍：把每人的「不肯跨过的那条线」念一遍，
问「这一场里有人被逼到线上了吗」。一次都没有，这场群戏是白写的。

## 链是往前推的，不是钉死的

每写完一卷，记一次**「他现在为什么还愿意做原来那件事」**。
答不上来，说明这个人这一卷没变——那就要么给他一件他没法拒绝的事，
要么承认这一卷是过渡卷。承认比硬推好。

## 不要做的事

- 不要一次给所有配角钉链。主线人物五六个人够了，钉多了没有一条会被真的对过。
- 不要把「不肯跨的线」写成口号（「他绝不会背叛朋友」）。口号不是线，
  拿它去对照一场戏，得不出任何结论。
- 不要用这条链去解释他所有的选择。链是用来**排除**的：照链排除掉不成立的动作，
  剩下的才需要理由。
