# 章首章尾各留一个钩子

## 钩子不是悬念，是一笔没结的账

把「悬念」当成一个气氛词去营造，写出来的东西读者记不住。
钩子是一笔**具体的、没有结清的账**：有人欠了谁、有一句话没说完、有一个东西不对劲。
读者翻页是因为想知道这笔账的下落，不是因为「感觉还有好戏」。

## 章尾留钩子：几式任选

- **一个动作停在半途**：他抬手去推门，门后传来第二个人的声音。
- **一句真话只说了一半**：说到关键处他自己改口了，理由却没给。
- **一个此前不存在的名字**，从别人嘴里冒出来，屋里所有人都认识，只有视角人物不认识。
- **代价已经定下，尚未支付**：救这个人要拿另一个人抵，而那个人还没被提到。
- **一件东西反常**：昨天还在的东西今天不见了，没有人提起。
- **有人替视角人物做了决定**，而他事先不知情。

选的时候问一句：**读者读完这一句，最想知道什么？**答得出来的就是钩子。

## 章尾不许做的事

- **不许总结**。「这一夜终于过去了」这类句子一出来，上一秒的账就被抹平了。
- **不许预告**。「下一章他将面对……」是目录，不是钩子。
- **不许拔高**。在一个具体动作之后接一段感慨，读者会从故事里掉出来。
- **不许同时留三笔账**。留两笔读者已经不知道该跟哪一笔。

## 章首兑现

钩子提出的是一个具体问题，**下一章的前三段必须开始回答它**。
隔了五章才想起来回答，就不叫兑现，叫换了话题。

兑现的最好方式不是解释，是**动作**：上一章门后那个人，这一章就站在屋里。
不解释、不回顾、不提醒，直接把那张脸给出来——读者自己会想起来。

## 自查

写完一章，把**最后一句**单独抄出来，贴在问题旁边问：读者现在最想知道什么？

- 答得出来 ⇒ 这一章有钩子。
- 答不上来 ⇒ 这一章没有钩子，改的是**章尾最后一场戏**，
  不是在最后一段加一句「未完待续」。

## 不要做的事

- 不要每章都用同一种钩子。连着五章都用「门外来人」，读者会开始预判。
- 不要在章尾把话说满。「他决定去复仇」把话说尽了，接下来只能更狠；
  「他决定去复仇，但没告诉任何人」才有下一章。
