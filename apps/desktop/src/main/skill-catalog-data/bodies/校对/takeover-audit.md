# 接手一本写到一半的书

改编自 zenstory-ai/oh-story-claudecode 的 story-import（先盘点再续写，MIT）。只搬方法，不搬原文。

写已经进行到一半的书，最大的错不是写不好，是**没接住**——
人物的性格漂回起点、三个月前埋的枪没人开、上一章停在天亮这一章又入夜。
原因都一样：动笔之前没盘点。先把书读完整，再落三张表。

## 第一张：人物此刻的现状

对每个出场过的人物记四样：**他现在在哪、他知道哪些事、他想要什么、
他最近一次出场干了什么**。注意是「此刻」——不是第一章设定里那个他，
是被中间这些章改变过的他。性格漂移就是从这里漏出去的。

## 第二张：已经埋下的伏笔

扫全文里所有「起了头没下文」的东西：提到没解释的物件、
许过没兑现的话、出现一次就消失的人物。一条一行，写明埋在第几章。
续写时要么接着用，要么明确让它们继续躺着——不能假装它们不存在。

## 第三张：断点

最后一章停在什么状态：什么时刻、谁在场、悬着哪口气。
续写从断点的下一秒开始，**不重述、不回顾**——读者刚读完上一章。

## 盘点落进素材，再动笔

三张表写进这本书的素材里存着。这不是流程仪式：
写到几十章之后你会忘了盘点过什么，表还在就能对。
续写过程中人物现状表跟着改——他每做一件事，表上那条就更新。

## 不要做的事

- 不要边读边改前文。第一遍只读不改，改前文会让你以为了解了其实没有。
- 不要把盘点写成读后感。表是给续写用的数据，不是给读者看的文字。
- 不要跳过盘点直接写。**省下的那一个钟头，会在第五章之后连本带利还回去。**
