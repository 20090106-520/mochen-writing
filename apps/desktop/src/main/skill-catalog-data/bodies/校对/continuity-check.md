# 回头核一遍前后

## 什么时候做

- 写完一卷；
- 或者写完一章之后，隔了一周以上才继续。

**不要**每写完一段就回头核——那时候你还记得，记得住的东西核不出问题。

## 核三样

### 一、时间

把这一卷里所有带时间标记的事排成一条线（哪一章第几天）。
冲突有两类：**顺序错了**（后发生的事写在了前面）与**间隔不对**
（「三天后」那句里，中间其实写了四天的事）。

### 二、人物状态

每个人物：现在在哪、身上有什么、知道哪些事、身体如何。
逐章对照。特别核**受伤与恢复**：第 3 章断的手，第 8 章不该能拧开瓶盖。

### 三、伏笔

这一卷埋了哪些**承诺给读者的东西**（提过没解释的名字、异常、没说出口的话）。
逐条问：解释了吗？没解释的，要么在这一卷里给一个方向，要么明确记进下一卷的待办。

## 结果怎么记

对不上的地方列成一张清单，**每条写清「在哪一章、与哪一处对不上」**。
只写「时间线有误」没有用——三周后你自己也不知道该改哪儿。

清单放在这本书的大纲或素材里。下一次动笔前先看它。

## 一条纪律

核出来的问题，**先改后加**。
不要因为「已经写到那里了」就把规则改松——那等于让前面的三十章变成另一个故事。

## 出处

本仓原创。
