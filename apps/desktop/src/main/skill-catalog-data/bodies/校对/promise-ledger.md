# 伏笔台账：埋了哪些、该在哪一章收

改编自 zenstory-ai/oh-story-claudecode 的 story-long-write（伏笔台账，MIT）。只搬方法，不搬原文。

## 为什么要有号

「那个提到过两次的名字」这句话，三个月后没人查得动。
给它一个号（F016、F049……），它就变成一条**可以在任何一份文稿里被引用**的东西。
章纲、正文、待办里都能指着同一条说话。

## 一行记四样

- **号**：F + 序号，不重排、不复用。
- **是什么**：一句话。读者当时以为的是什么。
- **埋在哪**：第几章。正文里原话引一句，便于日后回查。
- **回收章**：打算在第几章兑现；还没定的写「未定」。

多两栏也很有用：**优先级**（高 / 中 / 低）与**状态**（已兑现 / 待兑现 / 已放弃）。
状态是必需的——**放弃的伏笔也必须销号**，否则它会在表里挂到永远。

## 什么时候更新

**写完每一章就更新一次**，不要攒着。攒到月底统一补，你会补不全——
中间那些当时一闪而过的东西，事后根本想不起来。

写完这一章做三件事：

1. 这一章**新埋了什么**？登记。
2. 这一章**兑现了什么**？改状态，并把那一行留在表里（不许删行）。
3. 这一章**因为新出现的信息，哪条旧伏笔该改回收章**？改。

## 动笔前看它

开写之前扫一眼表，重点看三件事：

- **高优先级、离回收章近了的那几条**：这一章是不是该收了？
- **埋了很久还没动的**：要么这章收，要么改回收章。
  挂着不动是最坏的一种——读者已经忘了，兑现了也没人觉得是那回事。
- **状态是「已放弃」的**：确认正文里没有半句还在暗示它。

## 一条纪律

**兑现的章数可以推迟，但不能删。**
删掉一条是允许的（写不下去），代价是那一章的读者体验要重新想一遍；
删掉的同时必须在正文里给它一个交代——人物提一句「那件事后来没再提过」，
或者干脆换个方向。这比留着不说强。

## 不要做的事

- 不要建一张只记「已兑现」的表。只记完成项的表，长到一百章之后会全是空的。
- 不要在正文里**明写**「这是伏笔」。台账是给自己看的，不是给读者的。
- 不要把「作者临时想的一个点子」登记成伏笔。只有**读者能看见的**承诺才算。
