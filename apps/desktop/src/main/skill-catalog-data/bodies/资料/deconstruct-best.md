# 从对标作品里抽技法，不抄句子

## 拆文要拆出「手法」，不是「剧情」

最容易走偏的一种拆法，是把人家的剧情复述一遍，写完发现自己什么也没学到。
**剧情不可搬，搬了就成抄袭。**

要搬的是**手法**：它在哪里用了这一招、那一招解决了什么问题、
换成你的题材还能不能用。这三样抽出来，才算你的。

## 一段一段锚着原文拆

对着**一本具体的小说**（不要对着类型总结），按顺序拆：

1. **列出节点**：这一段发生了什么**状态变化**。
   写成「（谁）从 A 变成 B」，不是「（谁）做了什么事」。
2. **标情绪**：这个节点把读者的情绪推到哪一档（从 −9 到 +9 随意定，但一套标准用到底）。
3. **抽手法**：这一段用了什么招？一句话说清这一招**解决什么问题**。

三样缺一不可。只有 1 是复述，只有 3 是抄，只有 2 是空的。

## 抽完当场做两件事

### 一、给它一个可复用的名字

「主角在被人当众羞辱之后没有当场反击，而是记下了对方的名字」——
这不是手法名，这是情节。手法名应该是「延迟反击」，
并且要写清它的**适用条件**：被当众羞辱、实力不足以当场反击、且对方会继续出现。

有了名字和条件，它才能被你用在另一本书上。

### 二、评估它

抽到的手法逐条问：

- 它在这本书里解决了什么问题？
- 照搬到一个**完全不同的题材**上，还成立吗？
- 它有什么代价（节奏？人物厚度？篇幅？）？

三条都答得出来的，进你的模块库。
只有第一条答得出来的，是人家的专有做法，**不要学**。

## 模块库怎么用

攒到一定量之后，用它做两件事：

- **开新书之前**：从库里挑五到八个手法，试着拼成这一本书的骨架。
  拼得起来说明是通用手法；拼不起来说明你挑的都是题材专有的。
- **写不下去的时候**：翻库，找一个能解决当前这个问题的手法。

**模块库里存的必须是「手法 + 适用条件 + 代价」三件套**，
只存一句「某某书里用了个很妙的写法」等于没存。

## 不要做的事

- 不要整段复制原文进素材。**锚章记号 + 一句你自己的话概括**就够。
  需要时回去翻原书，比抄一份安全得多，也清楚得多。
- 不要拆自己正在写的书。自己写的东西不是「对标」。
- 不要拆完不评估。抽一百条手法不评估，等于抽了一百条别人的东西。
