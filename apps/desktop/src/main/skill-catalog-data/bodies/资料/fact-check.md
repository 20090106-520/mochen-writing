# 查清楚再写

本仓原创。查资料走本仓已有的**联网搜索**工具（对话区工具卡里那一枚，或输入区的「联网搜索」开关）。

## 什么时候必须查

- 具体的历史事件、日期、条约；
- 职业的真实流程（法医怎么验、律师怎么问、银行怎么办手续）；
- 地理：距离、地形、到下一个城镇要多久；
- 技术：某种机械、药物、通信方式在当时能不能做到。

**判定办法**：一个外行读者会不会挑出毛病？会，就查。
读者不挑的那些细节（衣服的颜色、街名的选择）随便写。

## 怎么查

1. **先问自己已经知道什么**，写下来。查是为了确认与补缺，不是从零开始。
2. **一次搜一件事**，不要把三个问题塞进一次搜索——搜出来的答案会混在一起，
   你会分不清哪条回答哪个问题。
3. **查到矛盾的说法时，两个都记下来**，并在正文里避开或明确选一个。
   读者看到两个版本，会觉得作者也不知道。
4. **来源要留着**。查到的链接与要点放进这本书的素材里，正文那段写完就不再改了。

## 查完之后

- 查出来的东西**不要全写进正文**。资料是给你用的，不是给读者的。
  正文只留能影响情节的那一两句，其余留在素材里备查。
- 查完发现真相比你想的有意思 ⇒ 停下来重写这一段，不要只用那个更有意思的细节当装饰。
- 查不到 ⇒ 在素材里如实写「未确认」，正文里绕开。
  **不要凭印象写**：一条编出来的细节被读者查到，比这段没写更伤。

## 一条纪律

虚构的部分可以随便编，但**掺在真实里的虚构必须交代清楚**。
读者分不清哪句是真的哪句是你编的，整本书的可信度就没了。
