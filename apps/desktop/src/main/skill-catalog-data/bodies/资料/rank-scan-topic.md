# 扫榜看模式，别只看排名

改编自 zenstory-ai/oh-story-claudecode 的 story-long-scan（扫榜方法，MIT）。只搬方法，不搬原文。

查资料走本仓已有的**联网搜索**工具。这一条管的是动笔之前的另一门功课：
市场里现在什么活、什么熟、什么已经写烂了。

## 排名是线索，模式才是信号

一本上了榜首说明不了什么——它可能靠作者的名气、平台的推位、
或者一次运气。**同一个元素在十几本书里反复出现**，那才是信号：
题材组合、设定套路、书名的起法、开篇的卖点。扫榜要提的是这些重复项，
不是记住谁排第几。

## 不同平台看的东西不同

免费流量型平台看的是**完读率**——读者刷到就点，点进来就得留住；
付费型平台看的是**追读与订阅**——读者肯为下一章掏钱。
所以前者吃节奏和钩子的密度，后者吃题材的黏性与长线。
看哪个平台的数据，就按哪个平台的成功标准下结论，别混着算。

## 每个方向过一遍可行性

趋势不等于你能写。扫出来的每个候选方向问三句：

1. **素材储备够不够**——这个题材要的知识、经验、资料，手里有吗？
2. **题材边界摸清了吗**——什么能写、什么不能碰、读者在哪条线上会翻脸？
3. **篇幅承载对不对**——这个题材是三万字能讲完的，还是得百万字起步？
   短讲长的会拖，长讲短的会散。

三句里有一句答不上来，先补功课再立项。

## 结论要带着动作

扫完的产出不是一份「市场报告」，是**下一步**：
写哪个方向、避开哪些写烂了的开头、跟哪几本书对标。
没有动作的扫榜是消遣。

## 不要做的事

- 不要拿一次搜索当全貌。榜单会波动，隔几天再看一眼再下结论。
- 不要因为一个题材火就写。火的东西竞争也最多，
  「火且你写得出来」两个条件都要满足。
- 不要把扫榜结果当剧本。市场告诉你读者在哪，故事还得是你自己的。
