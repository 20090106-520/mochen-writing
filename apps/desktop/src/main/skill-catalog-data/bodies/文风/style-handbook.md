# 给这本书立一本文风手册

## 为什么要立一本

长篇写到几十章之后，最常见的退化不是写不动了，是**变成了另一个人**。
每一章都在「写好」，于是每一章都不像前面那些章。
作者本人也说不清自己原来的腔调是什么样了。

这时候需要一份能对着看的东西。而它**只能从这本书自己的段落里拆出来**——
不是从别人的范儿，也不是从「优秀小说应该怎么写」。

## 拆哪几段

从这本书**自己已经写完**的正文里挑 3–5 段，挑选标准：

- 是你写的时候最不费力的那几段（省力的段落最接近本能）。
- 覆盖不同场景：对话多的、动作多的、安静的一段。
- **不要挑你最喜欢的**。喜欢的段落往往是你当时在模仿某一篇。

## 拆哪几样

逐样记录，每样给一句可执行的描述，不要只贴例句：

1. **句子长度**：最短几句是多长？最长几句是多长？多数落在哪一档？
2. **标点脾气**：破折号用不用？用得多不多？分号？省略号？
3. **叙述距离**：贴着人物（只看得到他看得到的），还是退后一步（读者比他知道得多）？
4. **对白与叙述的比例**：一章里大概几成是对白？
5. **每段的收法**：多数段落在什么位置停——一句话说完，还是一个动作结束，还是一个画面？
6. **硬碰硬的地方怎么处理**：冲突戏里写情绪，还是写动作？

## 手册怎么用

写新的一章之前读一遍，写完之后拿它对一遍，**只对上面这六样**。

对不上的地方，先问是哪一处在偏：

- 是这一章不适合这条规律（那就在手册里给它开一个例外，写清为什么），
- 还是这一章跑偏了。

**关键是允许例外**。手册是量尺，不是宪法。
一板一眼照着它写出来的章节会齐，但也会平。

## 一条纪律

**手册只描述这本书自己的句子，不许变成「优秀小说的写法」。**
一旦开始往手册里写「要有画面感」这类条目，它就废了——
那种条目谁都能写，写了等于没写。

## 不要做的事

- 不要从别人的作品里拆。这是最容易犯的一条：拆出来的会是那个作者的腔调，
  写完一本书读起来像在替别人续。
- 不要拆对话段就只记对白。对白之外的叙述才是被忽略的那一半。
- 不要在开书之前立手册。**没有样本可拆**，立出来的只能是别人的东西。
