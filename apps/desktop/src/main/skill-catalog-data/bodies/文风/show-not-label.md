# 别替读者下结论

改编自 PenglongHuang/chinese-novelist-skill 的核心法则「展示而非讲述」（MIT）。只搬方法，不搬原文。

## 结论是读者自己的活

叙述者一写「他很愤怒」「气氛压抑下来」「她的心里五味杂陈」，
这段话就**替读者把活干了**。读者本来要自己从动作里读出愤怒，
现在只需要点个头——他点了，人也就走了。

写出来的东西没有重量，正是因为它是一句**评价**，不是一件事。

## 换法只有三种

### 一、换成动作

「他很愤怒」→「他把杯子放回桌上，放得太重，水溅到袖子上，他没有擦。」

判据：这个动作能不能被拍下来？拍不下来的那些，多半是评价。

### 二、换成物件

「气氛压抑」→「桌上的茶凉透了，没人动过。桌上那盏灯只点了一半。」

物件是替人物计数的：桌上有几样东西、哪一样是歪的，
读者自己会算出此刻发生了什么。

### 三、换成没说出口的那半句

「她很失望」→「她把话咽回去了，改口问他路上冷不冷。」

**咽回去的那半句比说出口的重要**——它同时给了情绪、给了关系、给了下一步。

## 一处最容易漏的地方：环境描写

「夜色深沉」「寒风刺骨」「灯火阑珊」这类句子，
写的是作者的心情，不是这个地方的样子。
把它们换成**能被这一章里的人物注意到的东西**，同样的氛围就出来了，
而且是这一章独有的氛围。

## 自查的一招

把全章里所有带评价色彩的词圈出来（很、非常、似乎、仿佛、显然、顿时、无比）。
圈完数一数：**超过五个，这一章就在替读者下结论。**

逐个问：这个词后面跟着的那个事实，能不能直接写出来？

## 不要做的事

- 不要为了「展示」而堆细节。堆到读者要自己拼，那就是另一种没写清楚。
- 不要在动作后面再补一句解释。「他摔了门，显然是气急了」——
  前面那个门已经把话说完了。
- 不要把这条当成禁令。**叙述者有权直接说**，
  只是要知道自己正在替读者做决定，且这个决定值得做。
