# 让人物说话不像一个人

## 症状先说清

读一段对话写不下去、或者写完觉得「谁在说话」，
多半不是文笔问题——是**所有人物都在用叙述者的腔调说话**。
叙述者的话是「他感到一阵莫名的愤怒」，人物的话是「你把门关上了」。

## 忌讳法

给每个主要人物定**一句他绝不会这样说的话**。不是口头禅（口头禅是装饰），
是**忌讳**——他宁可用别的绕过去，也不肯说的那种话。

例：

- 老账房：忌讳直说「我不行」。他会把事情接下来，做不完，也不会说自己不行。
- 少年：忌讳说「我想」。他的所有愿望都要包在一句请求里。
- 掌柜：忌讳提自己的名字。他永远用「店里的规矩」代替主语。

忌讳一旦定下，这个人物的**回避方式**就有了形状，后面每句话都能照它校。

## 写完之后对一遍

把对白单独抽出来，一行一行地问：**这句是这个人会说的吗？**
不是就改。不是改人物，是改那句话的**说法**。

## 三条容易犯的错

1. **让人物解释自己的动机**。人物不会说「因为我妈去世那年我答应过不再哭」，
   他会说「茶凉了」。
2. **让所有人物都更聪明**。把话说得利落不是聪明，是没有障碍。
   笨拙的那句常常更好，因为它是真的。
3. **用语气词代替性格**。「嗯……」「那个……」加多了谁都是同一个人。
   忌讳比语气词有用得多。
