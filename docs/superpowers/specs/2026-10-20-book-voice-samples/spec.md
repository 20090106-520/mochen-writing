# 本书原句样本（生成端动态段 · 把「通用范例句」换成本书自己的句子）

- 日期：2026-10-20
- 来源：用户原话——「主要的就是更像人类文比更好更细腻更流畅，**不要用通用的模板，也不要用模板**」。
- 状态：新增两段**动态段**（与 `bookFlavorSentence` / `openingsSentence` / `dialogueBalanceSentence` /
  `styleProfileSentence` 同类同分工），**只注入生成端**：不新增扫描判据、不写数值上限、不编阈值、不进任何闸。

## 一、病因（自审结论）

把生成端的常驻段逐个摊开数了一遍，一共十一处，分成两类：

| 段 | 住哪 | 形状 |
| --- | --- | --- |
| `AI_FLAVOR_INSTRUCTION` | 静态常量 | 词表 + 句法叮嘱（词表取自 `AI_FLAVOR_TERMS`，与体检同源） |
| `DE_AI_FLAVOR_STRUCTURE_INSTRUCTION` | 静态常量 | 结构级十禁（数值上限与扫描端起报线同源） |
| `QUALITY_INSTRUCTION` | 静态常量 | 五条手法，**例子是本仓自造的通用句** |
| `NARRATIVE_CRAFT_INSTRUCTION` | 静态常量 | 五条展开方式，**例子同上** |
| `HUMAN_CRAFT_INSTRUCTION` | 静态常量 | 四条正向维度 |
| `HUMAN_DIALOGUE_INSTRUCTION` | 静态常量 | 四条对话口径，**例子同上** |
| `DETAIL_AND_BEAT_INSTRUCTION` | 静态常量 | 详略三测 + 章末最后一拍，**例子同上** |
| `PLAN_MODE_INSTRUCTION` / `WEB_SEARCH_INSTRUCTION` | 静态常量 | 与文风无关（模式与工具），不在本刀范围 |
| `bookFlavorSentence` | 动态 | 本书**用滥**的写法点名避开（向下拉） |
| `openingsSentence` | 动态 | 各章开头句点名，叮嘱换进法（防流水线） |
| `dialogueBalanceSentence` | 动态 | 本章对话过密／过闷时出声 |
| `styleProfileSentence` | 动态 | 本书腔调的**四维读数**（防漂移） |

**缺的那一格**：四个动态段里，三个是「避开／别写重」（向下拉），一个是「保持读数」（防漂移）——
**没有一处把这本书自己写得好的句子摆给模型看**。模型手上能照的正面样本，只有那七段里
本仓自造的通用句：「她把茶杯推过去。『喝吧。』」「他把碗放下。手在桌沿停了停。」「他进屋，先去关窗」
「搪瓷缸」「蓝布工装」。照着这些仿写，写出来的是**本仓的示范腔**，不是这本书的腔——
这正是用户说的「通用的模板」。

## 二、本刀做什么

只做一件事：**从本书已完稿正文里原样摘出这本书自己的句子，摆给这一轮**。

1. `apps/desktop/src/main/prompt-assembly.ts`（改）新增两个动态段函数 + 两个常量：
   - `BOOK_SAMPLE_CHARS = 40`——每枚样本的**展示额度**（截断只为「别把整章倒进提示词」，
     与 `CHAPTER_OPENING_CHARS = 24` 同类，**不是判据**）；
   - `BOOK_SAMPLE_MIN_SENTENCES = 3`——摆得出「首／中／尾」三枚位置的**结构性下限**（不是质量线）；
   - `voiceSampleSentence(assembled)`——**语感样本**：本书句长的实际**下沿／中沿／上沿**三枚原句；
   - `dialogueSampleSentence(assembled)`——**对白样本**：本书对白句的同样三枚。
2. `defaultPromptFor` 末尾（`styleProfileSentence` 之后）按「有样本才加」注入两段。
3. `apps/desktop/src/main/agent-service-prompt.test.ts`（改）新增一个 `describe` 覆盖抽取口径与边界。
4. **七段静态常量一字不改、`aiFlavorGate`／`rankDrafts`／store／IPC／夹具一概不动**。

## 三、取舍（为什么这么切）

- **为什么不去改那七段静态常量**：它们是**方法与纪律**（禁什么、用什么替代），而且几处数值上限与
  扫描端 `AI_FLAVOR_STRUCTURE_MIN_COUNT`、退稿闸同吃一枚数字（生成端写明上限 ⇒ 扫描端同批建判据）。
  动它们就是动判据口径，得重跑阈值校准——不在本刀。本刀改用最轻的落点：**补一层本书原句**，
  并在段里明说「前面各段里给的例子**只是示意**，真要照的是这几条本书原句」——
  把范例句**降级为示意**，正面样本交给这本书自己。这一句就是用户「不要用通用模板」的落点。
- **为什么只取「已完稿」的正文（`active === false`）**：当前章是**半截草稿**。拿它当范本，
  模型会把上一轮自己的毛病（AI 腔、打转、潦草）抄进这一轮——那是**放大**而不是校准。
  `openingsSentence` 取的是全书的头（防抄自己），本刀取的是**已收笔**的身子（照自己的腔）。
- **为什么三枚位置是「首／中／尾」而不是编出来的长度区间**：三枚是**数据算出来的位置**
  （按句长排序取首、取中、取尾），**没有一个自定阈值**——§一百三十四 立下的「无真人语料分位不得编数」
  在这一刀上是天然满足的：本刀根本不写数，只**报数**。
- **为什么切句与对白判定都复用既有真身**：切句走 `sentencesOf`（与句长节奏、复读、退稿闸同一条
  lookbehind 口径）；「是不是对白句」走 `dialogueBalance(sentence).quoted > 0`（引号配对只住
  `dialogue.ts` 的 `scanQuotes` 一处，不另写一套引号规则）。两处都不新造。
- **为什么句数不足三句就不注入**：三枚位置是这个段的**结构**——不足三句摆不出下沿与上沿，
  硬摆就是拿两三句糊成「这本书的语感」。它同时天然把「开书第一轮」（还没有已完稿正文）
  挡在门外：开书之前没有样本可摘，不注入空段（与 `styleProfileSentence` 的 `STYLE_PROFILE_MIN_CHARS`
  同一条纪律）。
- **为什么不聚合、不排序成「最佳句」榜**：没有跨句判据能说哪句「更好」（那要真人语料分位），
  本刀只按长度摆两端与中位——**只摆原句，不作评价**。
- **为什么两段而不是一段**：语感样本管**叙述句**（用词、句长、断句），对白样本管**引号里的话**
  （人物口长、口气、断句），要叮嘱的事不同（一个是「长短跟着情绪走」，一个是「别让新人物说成另一个人」），
  合一段会让两种样本挤在一句叮嘱里。

## 四、不变量（要能机器判）

1. 只从 `kind === "chapter" && active === false` 的条目取样本——**当前章绝不进样本**。
2. 切句走 `sentencesOf`（改回自切一遍句就红）。
3. 三枚样本的「N 字」读数**逐位等于** `sentencesOf` 切出的句子长度（字数为句长口径，含句末标点）。
4. 三枚样本是按句长排序后的**首／中／尾**，不是随机、不是按出现序。
5. 已完稿句数 < `BOOK_SAMPLE_MIN_SENTENCES` ⇒ 返回空串（不注入空段）。
6. 对白样本的每一枚都满足 `dialogueBalance(sentence).quoted > 0`。
7. 单枚超 `BOOK_SAMPLE_CHARS` ⇒ 截断并带「…」，原文不整句进提示词。
8. 两段落点在 `styleProfileSentence` 之后；非 `chapter` 条目（人物卡等）不参与。

## 五、验收

1. 新增用例（`agent-service-prompt.test.ts`）全过；
2. **变异验证**：① 去掉 `active === false` 过滤 ⇒ 「当前章不算样本」用例红；
   ② 把 `pickByLength` 的首／尾改成按出现序取 ⇒ 三枚顺序用例红；
3. 全仓 `corepack pnpm verify` 打出 `VERIFY_EXIT=0`；
4. 台账追加 §一百四十一；
5. 仅本地 `git commit`，**不推送**。

## 六、如实记：本节收不掉的口子

- **七段静态里的通用例句仍在**：本刀只把它们的地位降为「示意」，没有逐句替换成本书原句
  （那要改七个常量的签名与全部相关用例，属于另一刀）。模型仍会读到那几枚自造例句。
- **样本只从「这次上下文装着的已完稿章节」里取**：装进上下文的篇由档案的 `context` 预算决定
  （主笔默认只带前 2 章尾部）。所以样本不等同于「全书普查」——这是**让它照自己最近的腔写**，
  不是立一本全书法典（后者是 `styleProfileSentence` 在做的另一件事）。
- **不做「哪句写得更好」的判断**：三枚是长度位置，不是质量榜。
- **样本可能撞上退役稿**：`active === false` 的条目里既有前情尾部也有全书摘要（300 字截断），
  后者取出的「句子」可能是截断残留。这是已知的粗糙处，本刀不为此新增判据（分辨两族要动装配层的数据形状）。
