# 人味写作（二）：补「片段内容／语言表达／逻辑思维／细节把控」四个正向维度（2026-10-18）

## 一、这一刀要收的是什么

用户逐字指令（明确叫停推送）：

> 「不要老是推送，人工创作特征太弱了片段内容、语言表达、逻辑思维、细节把控要更符合人类创作习惯不用推送」

点名的四个维度：**片段内容**、**语言表达**、**逻辑思维**、**细节把控**。
结论先写在前面：**这不是闸口问题，是生成端问题**——闸只能拦下限（复读、套话、节奏），
提不了上限；文本「像不像人写的」只能靠发给模型的**写作纪律**来治。

### 差距分析（回读 `apps/desktop/src/main/prompt-assembly.ts` 全文后逐条对表）

`defaultPromptFor` 每轮实际发给模型的常驻写作纪律共四段（装配数组第 299–305 行）：

| 段 | 常量 | 管什么 | 形态 |
| --- | --- | --- | --- |
| 一 | `AI_FLAVOR_INSTRUCTION` | 词与句：词表、认知转述、副词、句长 | 禁止清单 |
| 二 | `DE_AI_FLAVOR_STRUCTURE_INSTRUCTION` | 结构：破折号／否定排比／对偶／明喻／抽象主语／章末／开篇／引号／反差模板／打转 | 禁止清单（①–⑩） |
| 三 | `QUALITY_INSTRUCTION` | 细腻度：五感、具体名词、对话节拍、角色声音、续写衔接 | 半正半禁（5 条） |
| 四 | `NARRATIVE_CRAFT_INSTRUCTION` | 展开方式：演情绪／拆节拍／环境映心情／过渡锚／快慢分 | 正向（5 条） |

对着用户点名的四个维度：

| 用户点名的维度 | 现状 | 判读 |
| --- | --- | --- |
| **语言表达** | 一、二、三、四段共二十余条都在管（词、句长、修辞、对话、句式） | **已覆盖**，不缺 |
| **细节把控** | 三段第 2 条（具体名词）＋四段第 3 条（环境写具体的物） | **半个**：只有「写具体」，没有「该留哪个、该删哪些」——取舍是缺的 |
| **片段内容** | **一条都没有**（没有任何一段说「一场戏要有事发生」） | **缺** |
| **逻辑思维** | **一条都没有**（没有任何一段说「动机要立得住、事件要有因果」） | **缺** |

两个结构性病因（这才是「人工创作特征太弱」的来路）：

1. **四段九成是禁止清单**——「别写什么」写了几十条，「该怎么想」一条没有。
   只挨骂不给方法的模型，写出来的是「谨慎、均匀、无色」的散文，那本身就是机器味。
2. **缺的两维恰是分水岭**：机器写出来的场次往往**没有事件只有氛围**（内容空），
   人物的决定**没有来路**、事件靠「然后」串（逻辑不成立）。这两样正是人写与机器写最显著的差别。

## 二、纪律

1. **先红后绿**（TDD）：判据先写成红的，再动实现。
2. **不重复叮嘱**：新段与既有四段的分工要写清楚，同一件事不许两处说（既有四段不删不改，
   只在装配数组里加一段——动旧段会牵动既有 5 条提示词判据，收益不抵票据）。
3. **不能机器判的不硬上正则**（§一百零五 既定取舍）：这四条都要读**整场戏的上下文**才判得准
   （「这场有没有事件」「动机立不立得住」不是正则能扫的），**只进生成端、不设扫描判据**；
   扫描端能扫的那部分（情绪直陈、环境套话、复读句）各有同批判据，新段**不重复叮嘱**。
4. **外部检测器不作效果评估依据**（项目记忆）：朱雀读数抖动、且不给逐句标红，
   效果只能由本仓判据 ＋ 作者目检闭环。
5. **用户叫停推送**：本刀只在本地提交，**不 push、不换绑 README 门禁、不读 CI**，
   收口项如实留档（见第六节）。

## 三、改法（精确到文件与常量）

### 1) 生成端：`apps/desktop/src/main/prompt-assembly.ts`

新增常驻常量 `HUMAN_CRAFT_INSTRUCTION`（四条，一条对应用户点名的一个维度，
照旧给**可执行判据**，不空喊「写得像人一点」）：

1. **逻辑要立得住**（逻辑思维）——人物做决定前先定「他此刻想要什么、怕什么」，
   动机要能从性格／前文／当下处境推出来；上一场的结果带进下一场（因果，不是「然后」）；
   允许做**不利于剧情但符合性格**的选择、允许事与愿违；别把一切整理得太整齐，
   允许留下读者自己能补的缝隙。**禁事后补丁**（「其实他早就知道」）。
2. **每场戏都要有事发生**（片段内容）——动笔前先定这一场的「那件事」：谁想要什么、谁挡着、
   结尾比开头变了什么（关系／信息／处境至少变一样），变不了的场不写；
   禁概述式推进（「转眼三天过去，两人已经和好」）；一场给一到两处转折，不塞三个事件，
   也不只有氛围没有事。
3. **细节选得准、留得少**（细节把控）——一段只留一到两个**能承担意义**的细节，其余删；
   同一物件可反复出现但每次要变（茶盏 → 没擦的茶渍 → 碎在地上的茶盏），是回响不是复读；
   该省的直接跳（走路／掏钱／开门），该慢的多写两拍（情绪转折的那个动作）。
4. **句子跟着情绪走**（语言表达，**正向**）——紧张处短句／断句／动作句，舒缓处才用长句，
   不是随机错落而是跟着情绪；词要长在人物身上（码头工说「缆绳」不叫「绳索」）；
   允许不完整、口语、半句话；**不必句句漂亮**——真人写的有平句、有笨句、有毛边，
   通篇精雕反而露机器味。

落点：`defaultPromptFor` 装配数组里**紧接 `NARRATIVE_CRAFT_INSTRUCTION` 之后**
（去味三段 → 细腻度 → 叙事手法 → **人性化创作** → 动态段）。
