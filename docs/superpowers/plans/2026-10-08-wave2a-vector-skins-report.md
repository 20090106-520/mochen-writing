## 判的是什么

用户批准的四条范围里，这一波落两件：

1. **扩充带画的场景皮肤**——广场的入场条件仍是「有画」，所以增加只能是增加带画的，不是恢复素面配色；
2. **素材分工**：原话「全部我用 ImageGen 自绘（推荐），我自己提供图，给我什么样的，我让他给你做就行了」。
   实际通路：ImageGen 从波2 起持续返回 **403**，用户供图也未到。
   ⇒ 按既定规则处理：**缺素材不编素材、不做假控件凑形似**。
   这一波因此改走**仓内矢量**（参数化生成 SVG），并把矢量的质量门槛提到「和位图同一张眼睛关」，
   而不是降格成「凑数占位」。等位图到手，逐张换文件即可，枚举 id 与皮肤表都不用动。

## 三道闸（这一批的质量不是「我觉得像」）

v1 那批是我自己判**不合格**的：鲸读成穹顶、书阁读成梯子、广场八张里有三张读成「没有画」——
而「没有画」正是用户连着两次否掉的那件事。所以 v2 把判断从眼睛挪到闸上，眼睛只做最后一关。

1. **调色板级（生成时直接抛）**：每个取样点与中段做感知亮度差（sRGB 线性化后的
   `0.2126R'+0.7152G'+0.0722B'`），间隔 < 22 就不出图。
   这一闸在开发过程中**真红过**：`book-boat-night 主体与中段的亮度间隔只有 3`。
   处置是**重新打光**（夜景给主体自身发光 + 抬亮两缘三段），不是把阈值调低。
2. **像素级（光栅化后量）**：`.superpowers/sdd/tmp-check-art-readable.mjs` 把每张在页面里
   画成 320×180（和广场卡同一量级）后读像素，三条硬判据——
   `G1` 分层桶数 ≥4（只有渐变=没有画）、`G2` 两缘各自的亮度跨度 ≥18 且与中段均值差 ≥10、
   `G3` 中段水平边缘能量 ≤4 且两缘至少是它的 2 倍（中段必须安静）。
   首轮 **4/6 红**，红因逐条对应到具体图层，修完 6/6 过。
3. **反向用例**：闸末尾喂一张只有渐变的空图，**必须判红**。
   它红了才算这组数字有鉴别力，而不是恒真。当前输出
   `PASS 反向用例：空渐变判红 | 缘跨=14.9/14.9 缘中差=0.0/0.0`。

## 目检三轮，每轮都是「看图 → 找出处 → 改代码」

- **v2-a**：环境色带用矩形 + 硬渐变，横贯全幅 → 中段被抬亮（违反规则 1），
  并在 x=700/1860 留下竖直切口，把月盘横切成三节。
- **v2-b**：改成左右两缘的径向雾块、山体收口改斜坡、前景改弧形岸石；
  又发现灯塔上半身压在**禁止的上 12%** 里 → 整栋下移 60px；光柱与天窗光切进正文落点 → 收口到 x≤720。
- **v2-c**：无损图上还剩两处「板感」。用 `.superpowers/sdd/tmp-find-seam.mjs`
  做逐行/逐列一阶差分定位——**整行平均 8.4 的跳变其实全在左缘**（左 29.5 / 中 0.19 / 右 1.12），
  峰是亭内那张 26px 高的稿纸（合法主体细节），右半屏并没有板边。
  真正的两处是：巨石被圆滑闭合成一枚磨砂玻璃罩（改成多段折线 + 只给棱线受光 + 夜石比水暗），
  以及水面反光带 0→0.85 只走 79px（摊到 0→0.42 / 132px）。

## 诚实账（没做到的）

- **仍然没有人物立绘**。矢量画得出海、舟、灯、阁，画不出「蓝发鲸耳的汐」那种角色插画，
  所以这一族名字里不挂「汐」。位图到手前这条不撤。
- **生成器住在 git-ignored 的 `.superpowers/sdd/`**，不进版本库。
  ⇒ 唯一真身是那六个 SVG 成品，由 `appearance-skin-assets.test.ts` 读盘钉住存在性；
  「能不能重新生成一遍」目前不在仓库的保证范围内。这是这一波的已知取舍。
- **挂件层（波1b）仍阻塞**：契约与枚举已就位，运行时 token/CSS/表/素材必须同批出，
  缺的是 512×512 透明 PNG。没有用占位方块假装挂件。
- 次要文字 `--text-tertiary` 实测 2.87:1 那条，仍等用户的取舍，未擅自改。
